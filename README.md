# Sales Performance & Regional Analysis Dashboard | Power BI

## Project Overview

This project is an interactive Power BI dashboard created using Superstore sales data. The dashboard analyzes sales performance across different regions, categories, products, and time periods to provide a clear view of business performance.

## Tools & Technologies

* Power BI
* Power Query
* DAX
* CSV Dataset

## Project Objectives

* Analyze overall sales performance
* Compare sales across different regions
* Analyze category and product performance
* Identify sales trends over time
* Monitor key performance indicators (KPIs)
* Convert raw sales data into an interactive management dashboard

## Data Preparation

The dataset was imported into Power BI and prepared using Power Query.

Data preparation included:

* Checking and correcting data types
* Cleaning the dataset
* Handling data inconsistencies
* Preparing the data for analysis and visualization

## Dashboard Features

The dashboard includes:

* KPI cards for key sales metrics
* Regional sales analysis
* Category-wise sales analysis
* Product performance analysis
* Time-based sales trends
* Interactive filters and slicers
* Charts and visual reports

## Key Insights

The dashboard can be used to identify:

* High-performing and low-performing regions
* Top-performing product categories
* Sales trends over time
* Differences in regional performance
* Products contributing significantly to overall sales

## Project Files

* `Sales.pbix` – Power BI dashboard file
* `SuperStore_Sales_Dataset.csv` – Dataset used for analysis
* `Store Sales Dashboard.png` – Dashboard preview

## Purpose

This project was created as a practical Power BI project to develop skills in data cleaning, data visualization, dashboard development, KPI reporting, and business analysis.
